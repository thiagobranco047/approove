# Segurança

Encontrou uma vulnerabilidade no Approove? **Não abra issue pública.**
Use "Report a vulnerability" na aba **Security** deste repositório (aviso privado)
ou escreva para o mantenedor. Respondemos em até 3 dias úteis.

Este repositório é público: nenhum segredo vive no código. Chaves ficam só na Vercel
e em arquivos `.env*` locais (ignorados pelo git), e o CI roda gitleaks em todo push.
